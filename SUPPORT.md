# Getting help

## Start here

- **Documentation:** [pathrule.io/docs](https://www.pathrule.io/docs). The
  [quickstart](https://www.pathrule.io/docs/start/quickstart) and the
  [CLI reference](https://www.pathrule.io/docs/cli/commands) answer most setup questions.
- **Check your setup:** `pathrule doctor` shows what each connected agent receives and what is
  missing.

## Report a problem

- **Bugs:** open a [bug report](https://github.com/pathrule/pathrule/issues/new?template=bug_report.yml).
  Search the [existing issues](https://github.com/pathrule/pathrule/issues) first, and include the
  output of `pathrule version` and `pathrule doctor`.
- **Feature requests:** open a [feature request](https://github.com/pathrule/pathrule/issues/new?template=feature_request.yml).
- **Security vulnerabilities:** never in a public issue. Follow the [security policy](SECURITY.md).

## Pathrule Cloud

Questions about Pathrule Cloud accounts, team workspaces or billing are not handled in this
repository. Write to **hello@pathrule.io**.
